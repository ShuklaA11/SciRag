# Multichannel Variable-Size Convolution for Sentence Classification

## TL;DR
MVCNN is a convolution neural network architecture for sentence classification that combines multiple word embeddings and uses variable-size filters.

## Problem
Sentence classification tasks are challenging due to the complexity of natural language sentences, and existing methods often rely on fixed-size filters or parsing trees. Current CNN systems usually implement a convolution layer with fixed-size filters, which may not be effective in capturing long-range dependencies in sentences.

## Method
MVCNN combines multiple versions of pre-trained word embeddings and uses variable-size convolution filters to extract features of multigranular phrases. The architecture also employs mutual learning and pretraining to enhance system performance.

## Results
MVCNN achieves state-of-the-art performance on four tasks: small-scale binary, small-scale multi-class, large-scale Twitter sentiment prediction, and subjectivity classification.
