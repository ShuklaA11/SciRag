# Generating Natural Language Inference Chains

## TL;DR
A neural network is trained to generate entailed sentences from a source sentence, achieving an accuracy of 82%.

## Problem
The paper addresses the problem of recognizing textual entailment between two natural language sentences, which is essential for various NLP tasks. However, most NLP applications only provide single source sentences instead of sentence pairs, making it difficult to train models on this task.

## Method
The authors propose a sequence-to-sequence model using long short-term memory (LSTM) RNNs with attention mechanism to generate entailed sentences from a source sentence. The model consists of an encoder and a decoder, where the encoder maps the input sequence into a dense vector representation and the decoder generates the output sequence conditioned on that representation.

## Results
The authors achieve an accuracy of 82% in generating correct entailed sentences, which is an improvement of 10.3% over an LSTM baseline. The model can also generate natural language inference chains by recursively applying the entailment generation task.
