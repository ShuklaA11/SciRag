# Dynamic Memory Networks for Visual and Textual Question Answering

## TL;DR
The paper proposes improvements to the dynamic memory network (DMN) architecture for question answering, including a new input module for images.

## Problem
The DMN has achieved high accuracy on various language tasks, but its performance is unknown when supporting facts are not marked during training or when applied to visual questions. The authors aim to improve the DMN's ability to answer complex questions that require logical reasoning.

## Method
The authors propose several improvements to the DMN architecture, including a new input module with a two-level encoder and an input fusion layer for textual question answering, and a modification to gated recurrent units (GRU) with attention gates for memory updates. They also introduce a novel input module for images to enable visual question answering.

## Results
The proposed DMN+ model achieves state-of-the-art results on both the Visual Question Answering dataset and the bAbI-10k text question-answering dataset without supporting fact supervision.
