# Incorporating Discrete Translation Lexicons into Neural Machine Translation

## TL;DR
A method to improve Neural Machine Translation by incorporating discrete translation lexicons is proposed.

## Problem
Neural machine translation often mistranslates low-frequency content words, which are essential for understanding sentence meaning.

## Method
Discrete translation lexicons are used to calculate the probability of the next word in the translation candidate. This probability is combined with the standard NMT probability using linear interpolation or as a bias.

## Results
Experiments on two corpora show an improvement of 2.0-2.3 BLEU and 0.13-0.44 NIST score, and faster convergence time.
