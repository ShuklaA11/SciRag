# Learning to Compose Neural Networks for Question Answering

## TL;DR
A compositional, attentional model for answering questions about images and structured knowledge bases using dynamically assembled neural networks.

## Problem
The paper addresses the problem of question answering in various domains, including visual and structured knowledge bases, where existing approaches have limitations in handling complex queries and structured representations.

## Method
The proposed dynamic neural module network consists of two components: a collection of composable modules and a network layout predictor. The model learns to assemble these modules into larger structures using reinforcement learning with (world, question, answer) triples as supervision.

## Results
The approach achieves state-of-the-art results on benchmark datasets in both visual and structured domains, outperforming previous methods on two markedly different question answering tasks.
