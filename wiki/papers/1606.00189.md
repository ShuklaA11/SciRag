# Neural Network Translation Models for Grammatical Error Correction

## TL;DR
This paper proposes two neural network models to improve grammatical error correction by addressing limitations of traditional phrase-based statistical machine translation systems.

## Problem
Grammatical error correction is a challenging task due to the variability of error types and syntactic/semantic dependencies on surrounding context. Traditional rule-based and classification approaches are limited in performance.

## Method
The authors propose adding two neural network components, a neural network global lexicon model (NNGLM) and a neural network joint model (NNJM), to address limitations of traditional phrase-based SMT systems. These models use continuous space representation of words and can learn non-linear mappings.

## Results
Experiments show that the addition of these two neural networks leads to significant improvements over a strong baseline, outperforming the current state-of-the-art in grammatical error correction.
