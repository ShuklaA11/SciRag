# SCIBERT: A Pretrained Language Model for Scientific Text

## TL;DR
SCIBERT is a pretrained language model for scientific text that improves performance on NLP tasks in the scientific domain.

## Problem
Obtaining large-scale annotated data for NLP tasks in the scientific domain is challenging and expensive, hindering progress in scientific NLP.

## Method
SCIBERT leverages unsupervised pretraining on a large multi-domain corpus of scientific publications to improve performance on downstream scientific NLP tasks. It uses the BERT model architecture but is trained on a corpus of scientific text instead of general domain corpora.

## Results
SCIBERT achieves statistically significant improvements over BERT and new state-of-the-art results on several tasks, including sequence tagging, sentence classification, and dependency parsing.
