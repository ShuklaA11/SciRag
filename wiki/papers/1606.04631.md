# Bidirectional Long-Short Term Memory for Video Description

## TL;DR
A novel video captioning framework, Bidirectional Long-Short Term Memory (BiLSTM), is proposed to capture bidirectional global temporal structure in videos.

## Problem
Existing video description approaches either ignore temporal information or only employ local contextual temporal knowledge, failing to comprehensively preserve sequential and visual information.

## Method
The BiLSTM framework combines a forward LSTM pass, a backward LSTM pass, with visual features from Convolutional Neural Networks (CNNs) for joint visual modelling. The obtained video representation is then fed into an LSTM-based language model as initialization.

## Results
Experimental results on the Microsoft Video Description corpus demonstrate the superiority of the proposed approach compared to state-of-the-art methods.
