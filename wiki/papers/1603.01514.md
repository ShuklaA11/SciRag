# A Bayesian Model of Multilingual Unsupervised Semantic Role Induction

## TL;DR
A Bayesian model for unsupervised semantic role induction in multiple languages using parallel corpora.

## Problem
The paper addresses the problem of unsupervised semantic role labeling (SRL) in multiple languages, where manually annotated corpora are insufficient to build supervised systems. This is particularly challenging in languages with sparse or non-informative resources.

## Method
The proposed joint Bayesian model consists of individual models for each language and cross-lingual latent variables that capture alignments between roles across languages. The model uses a generative approach, allowing evaluations in various scenarios without changing the model.

## Results
The results show that using parallel corpora can improve SRL performance, with the biggest impact being the increase in monolingual data rather than the alignment to another language.
