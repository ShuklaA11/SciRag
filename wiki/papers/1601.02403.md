# Argumentation Mining in User-Generated Web Discourse

## TL;DR
The paper explores argumentation mining in user-generated web discourse, creating a gold standard corpus and applying machine learning methods.

## Problem
The problem addressed is the lack of tools for analyzing arguments in user-generated web content, making it difficult to find evidence for or against controversial standpoints.

## Method
The authors create a new gold standard corpus of 90k tokens in 340 documents and experiment with several machine learning methods to identify argument components.

## Results
The findings show that argumentation mining is a feasible but challenging task, with the ability to extract argument gists and evidence for standpoints.
