# Contextual LSTM (CLSTM) models for Large scale NLP tasks

## TL;DR
This paper proposes a Contextual LSTM (CLSTM) model that incorporates contextual features to improve performance on NLP tasks.

## Problem
The problem addressed in this paper is the limitation of traditional language models in capturing long-range context and hierarchical sequential structure in text. Current language models often rely solely on words as features, neglecting the importance of context in determining word meaning and relationships.

## Method
The proposed CLSTM model extends the Long-Short Term Memory (LSTM) architecture by incorporating contextual features, such as topics, into the model. This is achieved through an extension of the LSTM model that uses both words and topics as features to capture hierarchical and long-range context in text.

## Results
Experiments on three NLP tasks - word prediction, next sentence selection, and sentence topic prediction - show significant improvements in performance when using the CLSTM model compared to baseline LSTM models. For example, relative accuracy improvements of 21% were achieved for the next sentence selection task on the Wikipedia dataset.
