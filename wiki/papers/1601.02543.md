# Evaluating the Performance of a Speech Recognition based System

## TL;DR
A method to evaluate speech solution performance without actual user testing, reducing time and cost.

## Problem
Evaluating speech solutions is expensive and time-consuming due to extensive testing with real users and analyzing logs for successful transactions.

## Method
The proposed method evaluates the performance of a speech solution by simulating user interactions at each node of the system, without actual people using the system. The method considers the perplexity of each node, which affects recognition accuracy.

## Results
This approach can identify performance bottlenecks before the system is used, saving evaluation time and expenses.
