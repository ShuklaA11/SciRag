# Prepositional Attachment Disambiguation Using Bilingual Parsing and Alignments

## TL;DR
A Dual Decomposition based algorithm is proposed to disambiguate Prepositional Phrase attachments in English using bilingual parsing and alignments.

## Problem
Prepositional Phrase attachment disambiguation is a problem in NLP that often leads to incorrect parse trees, especially in syntactically ambiguous languages like English. This can result in serious errors in translation for applications like Machine Translation.

## Method
The proposed algorithm uses Dual Decomposition based inference to enforce agreement between the parse trees from two languages as a constraint. It trains two separate parser models for English and Hindi using the MSTParser, and makes use of these models in the inferencing step with parallel English-Hindi sentence pairs and their word alignments.

## Results
Experiments on the English-Hindi language pair show an improvement of 10% over the baseline, where the baseline is the attachment predicted by the MSTParser model trained for English.
