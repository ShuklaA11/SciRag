# Question Answering via Integer Programming over Semi-Structured Knowledge

## TL;DR
A structured inference system called TableILP uses Integer Linear Programming to answer natural language questions by chaining multiple pieces of information.

## Problem
Answering science questions posed in natural language is an important AI challenge that requires non-trivial inference and knowledge beyond factoid retrieval. Current systems rely on shallow Information Retrieval (IR) and statistical correlation techniques, which are not suitable for questions requiring reasoning.

## Method
TableILP operates over a semi-structured knowledge base derived from text and uses Integer Linear Programming to find the best supported answer by chaining multiple pieces of information and combining parallel evidence. The system treats lexical constituents of the question and cells of potentially relevant tables as nodes in a large graph, and attempts to find a subgraph that 'best' supports an answer option.

## Results
TableILP significantly outperforms previous structured reasoning systems (+14% absolute) on a dataset of real, unseen science questions. It also improves upon a previous ILP formulation by 17.7%. When combined with unstructured inference methods, the ILP system boosts overall performance by +10%.
