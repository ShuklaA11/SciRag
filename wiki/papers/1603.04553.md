# Unsupervised Ranking Model for Entity Coreference Resolution

## TL;DR
A generative, unsupervised ranking model for entity coreference resolution achieves state-of-the-art performance on English data from CoNLL-2012.

## Problem
Entity coreference resolution is a critical component in many NLP tasks, but supervised systems rely on expensive annotated corpora. Unsupervised approaches are desirable, but previous unsupervised systems' performance falls behind supervised systems.

## Method
The proposed model factorizes the probabilities of coreference and uses independence assumptions to compute each mention's probability separately. It introduces resolution mode variables to determine how mentions should be resolved based on string-matching, precise-construct, or attribute-matching.

## Results
The unsupervised system achieves a 58.44% F1 score on the CoNLL metric, outperforming the Stanford deterministic system by 3.01%. This narrows the gap to supervised coreference resolution accuracy.
