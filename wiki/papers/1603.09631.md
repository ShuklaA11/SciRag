# Data Collection for Interactive Learning through the Dialog

## TL;DR
This paper presents a dataset to enable interactive learning in dialog systems through user interactions.

## Problem
Current dialog systems struggle with understanding poorly phrased questions and lack of structured information from knowledge bases.

## Method
The proposed dataset allows simulation of interactive learning, where users provide explanations and answers to improve system policies.

## Results
The dataset consists of 1900 collected dialogs, enabling evaluation of interactive learning in dialog systems.
