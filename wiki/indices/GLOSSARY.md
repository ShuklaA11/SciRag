# Glossary

Concept -> one-line definition.

- **[[bert|bert]]** — BERT is a pre-trained language model achieving state-of-the-art results in various natural language processing tasks.
- **[[bleu|bleu]]** — BLEU is a metric used to evaluate the quality of machine translations.
- **[[cnns|cnns]]** — A type of neural network that uses convolutional and pooling layers to extract spatial hierarchies of features.
- **[[gru|gru]]** — A type of recurrent neural network unit that updates its memory using gated mechanisms.
- **[[lstm|lstm]]** — A type of Recurrent Neural Network (RNN) designed to handle long-term dependencies in sequential data.
- **[[nlp|nlp]]** — Natural Language Processing (NLP) refers to the use of computational methods for analyzing, understanding, and generating human language.
- **[[rnns|rnns]]** — A type of recurrent neural network (RNN) designed to handle long-term dependencies, particularly through its LSTM variant.
